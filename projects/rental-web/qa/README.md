# rental-web QA 파이프라인 (PoC)

임대관리 앱의 **계산 로직**을 실제 데이터 주입 → 연산 → 손계산 기대값(골든 마스터) 비교로
검증하는 자동화 파이프라인입니다. "데이터를 넣고 연산해서 결과가 맞는지"를 테스트하는
전문 QA 에이전트 회사의 첫 PoC 사례입니다.

## 왜 필요한가

임대관리 앱은 화면이 잘 뜨는 것보다 **계산이 정확한지**가 훨씬 중요합니다.
보증금 합계, 납부액, 공용비용 차감, 수익, 월별 수입/비용/순이익, 퇴거 보증금 준비금,
보증금 초과, 계약 변동 등은 실제 데이터로 검증하기 어렵습니다. 이 파이프라인은
그 검증을 자동화합니다.

## 구조

```
qa/
├── lib/calc.js          # index.html의 계산 로직을 순수 JS 모듈로 추출 (DOM 의존 제거)
├── lib/gen-boundary.js  # 경계값 시나리오 자동 생성기 (불변식 검증)
├── lib/app-vm.js        # index.html 인라인 스크립트를 Node vm 샌드박스에서 구동하는 로더
├── data/scenarios.js    # 테스트 시나리오 데이터셋 + 손계산 기대값(골든 마스터)
├── run-qa.js            # 파이프라인 실행기: 데이터 주입 → 연산 → 기대값 비교
└── run-sync.js          # 동기화 검증: 실제 앱(vm 구동) 렌더 결과 vs calc.js 비교
```

## 실행

```bash
cd projects/rental-web
node qa/run-qa.js            # 골든 마스터 + 경계값 (52개 검증)
node qa/run-qa.js S1 S4      # 특정 시나리오만 실행
node qa/run-sync.js          # 동기화 검증 (실제 앱 vs calc.js, 97개 검증)
```

종료코드: `0` = 전체 통과, `1` = 실패 존재 (CI 연동 가능)

## 핵심 설계

1. **결정적 테스트**: `now`(Date)를 주입받아 날짜 의존 로직(상태 판정, 이번 달, 3개월 범위)을
   고정된 시점(2026-09-15) 기준으로 검증합니다. 실행할 때마다 같은 결과가 나옵니다.
2. **골든 마스터**: 각 시나리오의 기대값은 사람이 손으로 계산한 값입니다. 코드가 바뀌어도
   결과가 그대로인지 회귀 검증합니다.
3. **경계값 자동 생성**: `gen-boundary.js`는 손계산 대신 **불변식(invariant)**을 자동 검증합니다.
   30명 제한, 연/월/윤년 경계, 상태 판정 경계, 보증금 기준 경계, 3개월 연도 경계 등
   경계값에서 로직이 항상 성립해야 하는 규칙을 코드로 생성해 커버리지를 쉽게 확장합니다.
4. **로직 1:1 대응**: `calc.js`는 `index.html`의 함수와 주석으로 1:1 대응하도록 유지합니다.
   index.html 로직이 바뀌면 calc.js도 함께 바꿔야 합니다.
5. **동기화 검증 (드리프트 감지)**: `run-sync.js`는 `calc.js`를 신뢰하지 않고
   **index.html의 실제 인라인 스크립트를 Node `vm` 샌드박스에서 그대로 구동**합니다.
   DOM/IndexedDB는 최소 스텁으로 대체하고 `Date`를 고정해 결정적으로 만든 뒤,
   렌더링된 HTML에서 표시 숫자를 파싱해 골든 마스터 기대값과 비교합니다.
   calc.js와 실제 앱이 어긋나면(드리프트) 즉시 실패합니다.

## 발견 사항 (동기화 검증으로 확인된 실제 앱 동작)

- **음수 비용 표시**: 월별 비용에서 환급이 비용보다 큰 달(순환급)은 `cost > 0` 조건으로
  인해 `-N만원`이 아니라 **`-`(빈 값)로 표시**됩니다. 집계 합계에는 정확히 반영됩니다.
  (동기화 검증이 이 표시 규칙을 자동으로 검증합니다)

| S8 | 같은 호실 계약 변동(월세/관리비) |

### 경계값 (불변식 자동 검증)

| ID | 검증 내용 |
|----|-----------|
| B1 | 입주중 30명 제한: 29명 등록 가능 / 30명 등록 불가 / 퇴거 시 재등록 가능 |
| B2 | dayBefore: 연초/월초/윤년(2/29)/30일·31일 달 경계 |
| B3 | calcContractEnd: 입주일 + 2년 (윤년 2/29 → 3/1 처리) |
| B4 | 상태 판정: moveIn/moveOut이 오늘과 같은 날짜일 때 |
| B5 | 보증금 초과: 기준값과 같으면 초과 아님, +1이면 초과 |
| B6 | 3개월 준비금: 12월→1월 연도 경계, 범위 밖 퇴거 제외 |

## 확장 방향

- **시나리오 자동 생성**: 경계값(30명 제한, 연/월 경계, 2월 29일 등)을 자동으로 만들어 커버리지 확대
- **index.html과 동기화 검증**: calc.js가 index.html 로직과 어긋나지 않는지 자동 확인
- **CI 연동**: GitHub Actions에서 `node qa/run-qa.js` 실행해 실패를 숨기지 않음
- **다른 앱 확장**: 같은 패턴(로직 추출 + 골든 마스터)을 다른 계산형 앱에 적용
