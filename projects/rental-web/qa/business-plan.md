# QA 에이전트 회사 — 사업계획서

> 작성일: 2026-09-02 · "데이터 주입 → 연산 → 결과 검증"을 전문으로 하는 AI QA 회사
> 기술 검증(PoC): rental-web 계산 로직 QA 파이프라인 완성 (골든마스터 30 + 경계값 22 = 52개 검증, CI 연동)
> 회사명: 미정 (제안: **베리파이(Verify)** / **체크메이트(Checkmate)** / **검증랩(VerifyLab)**)

---

## 1. 한 줄 소개 (Elevator Pitch)

**"숫자가 많은 앱의 계산이 맞는지, AI 에이전트가 자동으로 검증해 드립니다."**

임대관리, 정산, 급여, 세금, 재고, 구독 결제 같은 **계산/비즈니스 로직이 핵심인 앱**은
"화면이 잘 뜨는지"보다 **"계산이 정확한지"**가 훨씬 중요합니다. 그런데 실제 데이터로
검증하려면 데이터를 만들고, 기대값을 손으로 계산하고, 경계값 시나리오를 일일이 구성해야
해서 사람이 하기엔 지겹고 실수하기 쉽습니다. 이 회사는 그 검증을 **AI 에이전트가 자동화**합니다.

## 2. 왜 지금인가 (시장 트렌드)

| 트렌드 | 내용 | 우리와의 연결 |
|---|---|---|
| **AI 에이전트 성숙** | 코드 작성·리뷰·테스트를 에이전트가 수행하는 시대 | 검증 파이프라인을 에이전트가 자동 구축·운영 |
| **계산형 앱 증가** | 임대관리·정산·재고·구독 등 숫자 중심 SaaS 확산 | 검증 수요 증가 |
| **CI/CD 표준화** | 모든 코드 변경이 자동 테스트를 거침 | 검증을 CI에 통합해 실패를 숨기지 않음 |
| **골든 마스터 패턴 확산** | 회귀 테스트의 표준 방법론 | 우리의 핵심 기술 |
| **인건비 부담** | 수동 QA는 비싸고 느림 | 에이전트 = 인건비 극소화, 마진 극대화 |

## 3. 사업모델 (수익화)

### A. 검증 서비스 (B2B) — 핵심
- 고객 앱의 계산 로직을 분석 → **순수 모듈로 추출** → **테스트 데이터셋 + 골든 마스터** 구축
- **경계값 시나리오 자동 생성**으로 커버리지 확대
- **CI 연동**으로 코드 변경 시마다 자동 검증
- 산출물: **검증 보고서** (어떤 시나리오가 통과/실패했는지)
- 가격: POC(개념검증) → 파일럿 → 정식 계약 단계별

### B. 검증 도구 (SaaS/라이선스)
- 이 PoC의 파이프라인(`calc.js` + `gen-boundary.js` + `run-qa.js`)을 **재사용 가능한 도구**로 패키징
- 계산형 앱에 붙이기만 하면 되는 **검증 SDK/템플릿** 판매

### C. 개발 대행 (부가)
- 계산 로직이 핵심인 앱 개발을 의뢰받아 **개발 + 검증을 함께** 납품
- 개발회사(agent-dev-company)의 직원 = AI 에이전트이므로 인건비 극소화

> **추천 우선순위**: A(검증 서비스)로 초기 현금 흐름 → B(도구화)로 스케일업 → C(개발 대행)로 확장

## 5. 차별화 (경쟁 vs 우리)

| 항목 | 일반 QA (화면 테스트) | 우리 (계산 로직 검증) |
|---|---|---|
| 초점 | 화면이 잘 뜨는지 | **계산이 맞는지** |
| 방법 | 수동/스크립트 클릭 | **데이터 주입 → 연산 → 골든 마스터 비교** |
| 경계값 | 수동 시나리오 | **불변식 자동 생성** |
| 회귀 | 코드 변경 시 재테스트 | **CI 자동 연동** |
| 인건비 | 높음 | **에이전트 = 극소화** |

**진입 장벽**: 계산 로직을 순수 모듈로 추출하고, 골든 마스터 + 경계값을 구축하는
**방법론과 도구**가 핵심. 이 PoC가 그 방법론을 검증한 첫 사례.

## 6. 기술 검증 현황 (이 기기 기준)

- ✅ **PoC 완성**: rental-web 계산 로직 QA 파이프라인 (`projects/rental-web/qa/`)
- ✅ **골든 마스터 8개 시나리오 (S1~S8)**: 건물 카드, 환급 차감, 상태 판정, 월별 수익, 3개월 준비금, 보증금 초과, 신규 입주, 계약 변동
- ✅ **경계값 6개 시나리오 (B1~B6)**: 30명 제한, 연/월/윤년 경계, 계약만료일, 상태 판정 경계, 보증금 기준, 3개월 연도 경계
- ✅ **52개 검증 전부 통과** (골든마스터 30 + 경계값 22)
- ✅ **CI 연동**: GitHub Actions `test-rental-web-qa` job — 코드 변경 시 자동 검증, 실패 시 빨간불
- ✅ **결정적 테스트**: `now` 주입으로 날짜 의존 로직을 고정 시점 기준 검증
- ✅ **로직 1:1 대응**: `calc.js`는 `index.html` 함수와 주석으로 대응
