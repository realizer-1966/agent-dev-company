# rental-web — 임대관리 앱

OnDev Store에 배포된 **임대관리 웹앱**입니다.

## ✨ 기능

- **건물별 관리**: 여러 건물을 등록하고 각 건물의 세입자 목록을 관리
- **세입자 정보**: 이름, 전화번호, 호실, 보증금, 월세, 관리비, 입주일, 퇴거일 기록
- **건물당 세입자 최대 30명** 제한 (요구사항 반영)
- **입주/퇴거 상태 자동 표시**: 퇴거일이 비어 있으면 "입주 중"으로 표시
- **세입자별 텍스트 + 이미지 기록**: 관리비 연체, 시설 점검, 상담 내역 등을 텍스트와 사진으로 기록
- **건물 요약**: 입주 중 인원, 월세 합계 자동 계산
- **오프라인 작동**: 모든 데이터는 브라우저 **IndexedDB**에 로컬 저장 (서버 전송 없음, 개인정보 안전)

## 🗂️ 구성

```
rental-web/
├── index.html      # 임대관리 앱 (HTML + Tailwind + JS)
├── icon.svg        # 앱 아이콘
├── app.json        # OnDev 메타데이터
└── rental-web.zip  # 배포용 ZIP
```

## 🚀 재배포

```bash
cd projects/rental-web
ZIP_B64=$(base64 < rental-web.zip | tr -d '\n')
curl -s -X POST https://ondev.store/api/deploy -H "Content-Type: application/json" -d "{
  \"app_id\": \"rental-web\",
  \"zip_b64\": \"$ZIP_B64\",
  \"app_type\": \"web_app\",
  \"site_map\": [\"/\"]
}"
```

## 💾 데이터 저장 방식

- **IndexedDB** 기반 — 새로고침해도, 인터넷이 끊겨도 데이터가 유지됩니다.
- 세입자별 기록(텍스트·이미지)은 base64로 인코딩되어 동일한 DB에 저장됩니다.
- 같은 브라우저에서만 접근 가능하며, 다른 기기로는 자동 동기화되지 않습니다.
- **백업/복원**: 헤더의 📤 백업 버튼으로 전체 데이터를 JSON 파일(`rental-backup-YYYY-MM-DD.json`)로 내보낼 수 있고, 📥 복원 버튼으로 해당 JSON 파일을 불러와 다른 기기·브라우저로 이관할 수 있습니다. 복원 시 기존 데이터를 덮어쓰기 전 확인 메시지가 표시됩니다.

## ⚠️ 참고

- 이미지 기록은 base64로 저장되므로 **많은 사진을 오래 쌓으면 저장 용량을 차지**할 수 있습니다. 중요 사진은 별도 백업을 권장합니다.
- 현재는 단일 기기 로컬 저장입니다. (구독/로그인/백업/동기화 기능은 추후 확장 가능)
