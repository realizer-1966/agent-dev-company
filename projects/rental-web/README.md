# rental-web — 임대관리 앱

OnDev Store에 배포된 **임대관리 웹앱**입니다.

## ✨ 기능

- **건물별 관리**: 여러 건물을 등록하고 각 건물의 세입자 목록을 관리
- **세입자 목록 정렬**: 등록순 / 호수순(숫자 오름차순, 호실 없는 세입자는 맨 뒤) / 이름순(한국어 localeCompare) 정렬. 선택 상태는 localStorage에 저장되어 새로고침 후에도 유지
- **입주 중 세입자만 표시 + 호실 그룹핑**: 건물 상세의 세입자 목록은 **현재 입주 중인 세입자만** 호실별 카드(그룹)로 보여줍니다. 퇴거한 세입자는 기본 목록에서 제외됩니다. 호실이 없는 입주 중 세입자는 "호실 없음" 그룹으로 표시됩니다.
- **호실 전체 이력**: 호실 카드를 클릭하면 그 호실에 과거부터 지금까지 거주했던 **모든 세입자 목록**(이름·입주일·퇴거일·상태·보증금/월세)이 입주일 오름차순으로 표시됩니다.
- **세입자 정보**: 이름, 전화번호, 호실, 보증금, 월세, 관리비, 입주일, 퇴거일 기록
- **건물당 세입자 최대 30명** 제한 (요구사항 반영)
- **입주/퇴거 상태 자동 표시**: 퇴거일이 비어 있으면 "입주 중"으로 표시
- **세입자별 텍스트 + 이미지 기록**: 관리비 연체, 시설 점검, 상담 내역 등을 텍스트와 사진으로 기록
- **사진 촬영 버튼**: 기록 작성 폼에서 📷 사진 촬영 버튼을 누르면 모바일/데스크톱의 카메라가 직접 열려 사진을 찍어 기록에 첨부할 수 있습니다(숨겨진 `<input type="file" capture="environment">`). capture 속성을 지원하지 않는 환경에서는 자동으로 파일 선택으로 동작하며, 파일 선택 버튼은 그대로 유지됩니다. 촬영/선택한 이미지는 기록 추가 전 미리보기로 표시됩니다.
- **기록 이미지 라이트박스 뷰어**: 기록 목록의 이미지를 클릭하면 새 탭이 아닌 앱 내부의 전체화면 라이트박스로 크게 표시합니다. 어두운 배경 위에 이미지를 중앙 정렬(object-contain)로 보여주며, X 버튼·배경 클릭·ESC 키로 닫을 수 있습니다. 좌우 화살표 버튼 또는 ←/→ 키로 같은 세입자의 다른 기록 이미지들 사이를 이동할 수 있고, 열려 있는 동안에는 배경 스크롤이 잠깁니다.
- **건물 요약**: 입주 중 인원, 월세 합계 자동 계산
- **오늘 입주기념일 + 월세 입금 체크**: 각 건물 카드에 오늘(월/일, 연도 무관) 입주한 세입자 목록을 표시하고, 입주 중인 세입자 우선으로 나열합니다. 각 항목 옆 체크박스로 현재 월 월세 입금 여부를 바로 토글할 수 있습니다(입금/미입금 색상 구분). 입주기념일 세입자가 없으면 "오늘 입주 기념일 없음" 안내가 표시됩니다.
- **같은 호수 신규 등록 시 이전 세입자 퇴거일 자동 설정**: 같은 호실(room)에 입주 중(active)이면서 퇴거일이 비어 있는 이전 세입자가 있으면, 새 세입자 등록 시 그 이전 세입자들의 퇴거일(moveOut)을 새 세입자의 입주일 하루 전 날짜로 자동 설정합니다. (예: 새 입주일 2026-08-10 → 이전 세입자 퇴거일 2026-08-09, 연/월 경계 처리 포함)
- **오프라인 작동**: 모든 데이터는 브라우저 **IndexedDB**에 로컬 저장 (서버 전송 없음, 개인정보 안전)

## 🗂️ 구성

```
rental-web/
├── index.html      # 임대관리 앱 (HTML + Tailwind + JS)
├── icon.svg        # 앱 아이콘
├── app.json        # OnDev 메타데이터
└── rental-web.zip  # 배포용 ZIP
```

## 🚀 재배포

```bash
cd projects/rental-web
ZIP_B64=$(base64 < rental-web.zip | tr -d '\n')
curl -s -X POST https://ondev.store/api/deploy -H "Content-Type: application/json" -d "{
  \"app_id\": \"rental-web\",
  \"zip_b64\": \"$ZIP_B64\",
  \"app_type\": \"website\",
  \"site_map\": [\"/\"]
}"
```

현재 배포 claim_url: https://ondev.store/claim/jm8r3n

## 💾 데이터 저장 방식

- **IndexedDB** 기반 — 새로고침해도, 인터넷이 끊겨도 데이터가 유지됩니다.
- 세입자별 기록(텍스트·이미지)은 base64로 인코딩되어 동일한 DB에 저장됩니다.
- 같은 브라우저에서만 접근 가능하며, 다른 기기로는 자동 동기화되지 않습니다.
- **백업/복원**: 헤더의 📤 백업 버튼으로 전체 데이터를 JSON 파일(`rental-backup-YYYY-MM-DD.json`)로 내보낼 수 있고, 📥 복원 버튼으로 해당 JSON 파일을 불러와 다른 기기·브라우저로 이관할 수 있습니다. 복원 시 기존 데이터를 덮어쓰기 전 확인 메시지가 표시됩니다.

## ⚠️ 참고

- 이미지 기록은 base64로 저장되므로 **많은 사진을 오래 쌓으면 저장 용량을 차지**할 수 있습니다. 중요 사진은 별도 백업을 권장합니다.
- 현재는 단일 기기 로컬 저장입니다. (구독/로그인/백업/동기화 기능은 추후 확장 가능)
