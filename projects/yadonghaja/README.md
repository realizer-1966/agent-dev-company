# 야!동하자 (Ya! Donghaja)

> 운동 메이트를 모집하고, 서로 격려하고, 미션을 수행하면 보상을 주는 모바일 웹앱

## 한 줄 소개

"혼자 하면 포기하기 쉬운 운동을, **메이트와 함께 미션으로 달성**하고 **포인트·배지·랭킹**으로 보상받는 웹앱"

- **정식 명칭**: 야!동하자
- **축약 표기**: 야!동 (앱 타이틀, 헤더 등 좁은 공간)

## v1 프로토타입 — 주요 기능

### 🤝 메이트 모집 (모집 탭)
- 운동 종류(헬스/러닝/홈트/자전거/요가/등산/걷기) · 온·오프라인 · 지역 · 요일 · 시간대 · 인원 조건으로 모집글 작성
- 종류 필터 칩(가로 스크롤) + "온라인만" 토글
- 모집글 신청 → 방장이 수락/거절 (로컬 시뮬레이션)
- 시드 더미 모집글 8건 노출 — 혼자 써도 "사람이 있는" 경험 제공

### ✅ 미션 시스템 (미션 탭)
- **일일 미션 3개**: 자정 리셋, 사진+한 줄 소감으로 인증 (+10P)
- **주간 챌린지**: 매주 월요일 갱신, 이번 주 인증 4회 달성 (+50P)
- **그룹 공동 미션**: 가입 그룹의 주간 인증 합계 목표 (+50P)
- **스트릭**: 연속 인증일 추적, 복권 아이템으로 1회 방어

### 🔥 격려 피드 (피드 탭)
- 인증 카드 타임라인 (최신순/응원많은순 정렬)
- 응원 버튼 3종: 🔥 파이팅 / 👍 대단해 / 💪 챙겼네
- 응원 보내기 +1P (일 5회), 응원 받기 +2P
- 내 인증 직후 더미 메이트가 랜덤 응원 (시뮬레이션)

### 🏆 보상 (프로필 탭)
- **포인트 정책**: 일일 미션 +10 / 전부 완료 보너스 +20 / 주간 +50 / 그룹 +50 / 스트릭 7일 +30 · 30일 +100
- **레벨 5단계**: 🌱 새싹 → 🔥 주니어 → ⚡ 시니어 → 🏅 에이스 → 👑 레전드 (150/400/900/2000P)
- **배지 6종**: 첫 발걸음, 일주일 개근, 한 달 개근, 인싸메이트, 미션 마스터, 단체생활
- **주간 랭킹**: 더미 유저 12명과 경쟁, 월요일 리셋

## 기술 (v1)

- **단일 `index.html`** — Vanilla JS + Tailwind CDN, 배포 의존성 최소화
- **IndexedDB** (`yadong-db`) — 스키마는 v2 Supabase 테이블과 1:1 대응 설계
- **인증샷**: `<input type="file" capture>` → 800px JPEG 리사이즈 압축 저장
- 모바일 우선 (360px 기준, 데스크톱 max-width 480px), 하단시트 모달, 접이식 패널

## ⚠️ v1 프로토타입 유의사항

1. **로컬 저장 전용** — 데이터는 이 브라우저의 IndexedDB에만 저장됩니다. 브라우저 데이터 삭제 시 소실되며 백업되지 않습니다.
2. **시드 데이터** — 모집글·피드·랭킹의 다른 "사용자"는 예시용 더미 데이터입니다. 실제 멀티유저는 v2(Supabase)에서 지원합니다.
3. **포인트는 가상** — 적립 포인트는 게이미피케이션 요소이며 환전/제휴는 v1에서 제공하지 않습니다.
