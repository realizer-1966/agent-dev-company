# FEAAS v2 아이디어 (MVP 범위 밖 — 구현 금지, 기록용)

> CEO 제공 FEAAS 설계 문서(2026-11-02)에서 분리한 2·3단계 및 기술 스택 기록. MVP(1단계 진단기)는 requirements.md만 따른다.

## 2단계 — Economic Forecast Engine (AI 자산운용 엔진)

- 실측 경제 데이터 수집: 금리·물가(CPI/PPI)·환율·GDP·고용·유동성·지정학 리스크 (금융 데이터 API)
- 오행 경제지수 산출 알고리즘: 5개 오행 지표 표준화 → 0~100 (MVP가 수동 슬라이더로 대체한 부분의 자동화)
- 경제환경 예측: 3개월·6개월·12개월 시나리오 (XGBoost/LightGBM, 시계열은 TFT/LSTM 비교 검증)
- 국면 판정 자동화: 복수 지표 조합 — 단일 지표 판정 금지(예: 금리 하락≠경기 회복)
- 과거 10~15년 데이터 백테스트 검증 게이트: 국면 분류 정확도 / 주식60:채권40 대비 성과 / MDD 감소 / 거래비용·세금 반영 효과 / 위기 국면 방어

## 3단계 — Asset Allocation Engine · 자동 운용

- 최적화 목적함: max_w [ w^T·mu − λ·w^T·Σ·w − γ·TC(w) ] — 위험회피 λ, 거래비용 민감도 γ
- 제약조건: 합 100 / 현금 비중 최소 10% / 특정 자산군 집중 상한 / 비유동성(부동산) 매매 제한 / 환율·신용위험 한도
- 리밸런싱 운영 주기(설계): 데이터 수집 매일·오행 점수 매주·국면 판정 매월·비중 재계산 매월·실제 리밸런싱 분기·비상 리밸런싱은 위험 한도 초과 시
- 균형도(EBI) 월간 자동 계산
- 기술 스택 후보: Python·PostgreSQL/TimescaleDB·PyPortfolioOpt/CVXPY·Google ADK 멀티에이전트(목·화·토·금·수·Risk·PortfolioOptimization Agent + Orchestrator)·Streamlit/웹 대시보드·스케줄러·API 서버
- 분리 원칙: LLM은 경제 보고서 읽기·설명 담당, 수치 계산은 수치 모델 담당

## 운영·데이터 노트

- Gold(금)과 은은 金 분류지만 위험 특성이 채권과 다르므로 실전에서는 위험을 별도 관리
- 직접 보유 주택은 총자산 진단에 포함하되 투자 가능 자금과 구분, 리츠와도 유형 구분
- 자동 배분 제안은 합계 100% 보정 + 허용 범위 clamp 규칙 유지 (MVP와 동일 규칙)
