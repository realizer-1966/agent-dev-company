## 1. 발주 개요

보유 자산을 오행 5자산군으로 분류·점수화하고, 포트폴리오의 오행 분포·균형도를 진단하며, 경제 국면 프리셋에 따른 목표 배분 제안과 리밸런싱 힌트를 제공하는 정적 웹앱(오행 자산 진단기)을 만든다. 이것은 FEAAS 3단계 개발 계획의 **1단계** 산물이며, 2·3단계(예측 엔진·백테스트·자동 운용)는 v2 기록으로 범위 밖이다(`docs/v2-ideas.md`).

FEAAS 3단계 개발 계획: ① 오행 자산 분류·점수화 → 진단기(본 MVP) ② 경제 국면 예측·배분 엔진 → v2 ③ 백테스트·자동 리밸런싱 → v2.

## 2. 오행×자산 분류 체계 (v2, 최종)

| 오행 | 경제적 의미 | 투자 대상(사전 정의 유형에 사용) |
|---|---|---|
| 목(木) | 성장과 확장 | 국내외 주식, AI·반도체·바이오·로봇, 벤처·스타트업 지분, 성장형 펀드 |
| 화(火) | 인플레이션과 에너지 | 에너지(유가·전력 인프라), 원자재, 산업금속 |
| 토(土) | 실물 기반과 축적 | 부동산, 토지, 상가, 리츠, 인프라, 임대수익 |
| 금(金) | 가치 보존과 금융 안정 | **금(Gold), 은(Silver)**, 국채, 우량 회사채, 정기예금, 확정금리형 보험 |
| 수(水) | 유동성과 순환 | 원화·달러 현금, 즉시인출 예금, CMA, MMF, 단기 금융상품 |

분류 유의사항:
- **Gold는 金**이다(v1의 火 배치는 폐기 — UI 어디에도 Gold를 火로 분류해선 안 된다).
- 금(Gold)과 채권은 모두 金이지만 위험 특성이 다르다 → 자산 유형 라벨(금/은/채권/예금)을 구분해 보여주고 5요소 기본 벡터를 서로 다르게 부여한다.
- 직접 보유 부동산(주택 등)은 총자산 진단에 포함하되, 투자 가능 자금과는 구분하며 리츠와도 유형을 구분한다(v2 운용 노트).

## 3. 기준 배분과 허용 범위 (FEAAS 기준 포트폴리오)

| 오행 | 기본 비중 | 허용 범위 |
|---|---|---|
| 목(木) | 30% | 20~40% |
| 火(화) | 10% | 5~15% |
| 土(토) | 20% | 10~30% |
| 金(금) | 25% | 20~35% |
| 水(수) | 15% | 10~30% |

- 합계 100%. 설계용 기준 비중이며 개인별 투자 권고가 아님(고지 필수).
- 이 비율을 고정 유지하지 않는다 — 경제 환경 변화에 따라 목표 비중을 조절한다. 허용 범위의 상단을 여럿 동시 적용하지 않으며, 어떤 제안도 합계 100%를 유지해야 한다.

## 4. 경제 국면 프리셋 (A~E)

| 국면 | 판정 감각 | 중심 오행 | 운용 방향 |
|---|---|---|---|
| A. 성장 확장기 | 목지수 높음+유동성 양호 | 목 | 주식·AI·반도체 비중 확대, 현금은 적정 유지 |
| B. 인플레이션 상승기 | 화지수 높음 | 화·금 | 원자재·에너지 검토, 금 비중 확대, 장기 고정금리 채권 위험 관리 |
| C. 실물경제 안정기 | 토지수 안정 | 토 | 임대수익·리츠·인프라, 현금흐름 안정 자산 |
| D. 금융 불안기 | 금지수 스트레스 | 금·수 | 우량 국채·금, 신용위험 자산 축소, 현금 확대 |
| E. 유동성 회복기 | 수지수 회복→성장 | 수→목 | 현금 일부 → 성장자산 이동, 기업실적 확인, 분할 매수 |

- 국면 판정은 복수 지표 조합으로 한다(예: 금리 하락만으로 회복 판정 금지 — 침체 때문에 금리가 떨어질 수 있음). MVP에서는 사용자가 국면을 직접 선택하거나 오행 경제지표를 수동 입력해 판정 힌트를 받는다.
- 각 국면의 목표 배분 테이블(합계 100, 각 오행 허용 범위 내, E는 수→목 이동 방향)은 코어 모듈의 데이터 상수로 정의하고 테스트로 검증한다.
- 오행 경제지표(수동 입력 대체): 목=GDP·기업이익·PMI·기술투자, 화=CPI·PPI·유가·원자재, 토=주택가격·임대수익·공실률, 금=신용스프레드·국채금리·금가격·재정, 수=통화량·유동성·달러지수·단기금리 — MVP에서는 0~100 슬라이더로 입력 가능해야 한다.
- 점수 해석 원칙(고지): 점수가 높다고 무조건 매수가 아니라 "그 자산군에 유리한 환경인지" 판단하는 지표다.

## 5. 상생 순환 모델 (개념도)

木→火 成長투자에서 수익 실현 / 火→土 수익을 실물로 전환 / 土→金 안정적 현금흐름 확보 / 金→水 이자·배당 현금화 / 水→木 현금을 새 성장투자에 투입. 사이클: 성장→가치 실현→축적→수익 확정→유동성 확보→재투자.
 고지 필수: 실제로 모든 자산이 이 순서대로 수익을 내거나 이동하는 것은 아니다.

## 6. 자산 5요소 점수 모델

모든 자산에 0~100의 5요소 점수: 성장성(木)·가치상승성(火)·안정성(土)·수익확정성(金)·유동성(水).
예시(유형별 기본 벡터 — Gold=金 반영): 주식 木90·火40·水30 / 에너지·원자재 火90·木30 / 부동산 土90·金40·水10 / 금(Gold) 金90·土40·火30 / 국채·정기예금 金90·土60·水20 / 현금·CMA 水95·金20. (최종 수치는 코어 모듈 상수로 정의, 유닛 테스트는 표에 존재하는 유형만 통과하도록)
핵심 규칙: 포트폴리오 오행 분포 = 금액 가중 평균(총합 기준).

## 7. 제품 요구사항 (MVP — FEAAS 1단계 오행 자산 진단기)

- 한국어 UI, 단일 페이지 정적 웹앱(코어 로직 = ES 모듈 JS, 테스트 = `node --test`, Node 22 내장 러너 — 외부 의존성 0)
- 자산 입력: 유형 선택(2장의 투자 대상 목록 + 직접 입력), 금액, 메모
- 유형별 오행 벡터 자동 제안 + 슬라이더 조정
- 포트폴리오 오행 분포 오각형 레이더 + 기준 배분(30/10/20/25/15) 오버레이 + 허용 범위 밴드
- 오행 경제지표 수동 입력(0~100 슬라이더)과 경제 국면 프리셋(A~E) 선택 → 목표 배분 제안(기준 배분에서 시프트, 허용 범위 내, 합 100 보정, "검토 후 적용" 성격 명시)
- 리밸런싱 힌트: |현재 비중 − 목표 비중| ≥ 5%p인 자산군만 이동 제안(경계 4.99%는 제안 없음)
- 균형도 지수(Energy Balance Index, 0~100): 5오행 분포가 기준 배분에 가까울수록 높고, 단일 오행 100% 집중이면 최저에 가까운 정의 — 정의 문서화 + 경계 테스트
- 상생 순환 다이어그램 뷰(개념도 고지 포함)
- 자산 데이터 서버 전송 없이 브라우저 로컬 처리, localStorage 저장·복원(선택 토글)
- 모바일 우선 반응형(375px 실측)
- 고지 문구 3종: (1) 투자 조언 아님·실제 판단 시 수익률·위험도 별도 검증 (2) 기준 배분은 설계용 기준·개인 권고 아님 (3) 상생 순환은 개념도
- Gold=金 표기 노트(v1 기능적 해석에서 변경된 사실 표기)

## 8. 기술 제안(권고)

- 위치: `projects/ohaeng-assets/`. 정적 웹앱(HTML/CSS/JS, 빌드 도구 불필요 — rental-web 유사 구조)
- 코어 로직은 UI와 분리된 순수 ES 모듈로: 유형→기본 벡터 / 금액 가중 평균 / 균형도(EBI) / 국면 프리셋→목표 배분 시프트(+허용 범위 clamp·합 100 보정) / 리밸런싱 제안 / 상생 매핑. 전부 `node --test` 유닛 테스트 대상.
- 배포: Cloudflare Pages(rental-web 인증 경로 재사용 — pages:write OAuth device-flow, 별도 프로젝트 이름)
- v2 전용 스택(Python/ML/DB)은 절대 MVP에 도입하지 않는다 — `docs/v2-ideas.md` 참조.

4. 고지 문구 3종 + Gold=金 노트 존재
