# FEAAS v2a 지표 정의서 — 오행 × 경제 데이터 매핑 (확정)

> 티켓 [FEAAS v2a] ② data 계층 산출물. 근거문서: `docs/requirements-v2.md` §0·§2·§5-1.
> 확정일: 2026-11-02(UTC). 구현: `engine/feaas/indicators.py`(`INDICATOR_DEFS`)·`engine/feaas/scores.py`.
> 이 문서는 req-v2 §2 표의 "PM 확정" 성격을 실측 가능성 근거와 함께 확정·기록한 것으로,
> 매핑·파생·방향·정책 변경 시 이 문서와 테스트를 함께 갱신한다.

## 1. 확정 원칙 (실측 가능성 기준)

1. **키 불필요**: FRED fredgraph.csv(`https://fred.stlouisfed.org/graph/fredgraph.csv?id=<ID>`)만
   사용 — API 키 없는 소스만(req-v2 §0). Stooq는 일별 CSV 다운로드(`?s=<sym>&i=d`).
2. **10년 이상 히스토리**: 표준화가 최근 10년 rolling percentile이므로, 해당 주기의
   10년 관측 수(월 120·일 2530)를 모두 확보해야 한다 — 이를 못 채우면 percentile이
   영구 부족(누락 표기)이 되어 지표가 실제로 동작하지 않는다.
3. **fredgraph 다운로드 상한 주의**: 라이선스 계열 시리즈는 `cosd`를 줘도 초기 이력이
   잘린다 — 후보마다 실제 응답을 검증한 뒤 확정한다(§3 실측 표).

## 4. 표준화 정책 (req-v2 §5-1 — 확정 고정, tests/test_scores.py)

1. **결측**: `.`·빈칸·`null`/`NA`/`NaN`/`-` → None → **마지막값 carry-forward**.
   선두 구간 None은 채우지 않고 유지(그 시점 누락 표기).
2. **percentile 정의**: `p = 100 × #{w ≤ v} / n`(현재를 포함한 직전 window개 관측,
   None 제외) — 최대 100·최소 100/n. 동률 포함 규약.
3. **역방향**: 100 − p (`scores.invert`).
4. **10년 부족(window개 관측 미만) → 누락 표기(None)** 채택. 감쇠 페널티 미채택 —
   근거: req §2 '판정 불가(데이터 부족) 시 국면=null·이유 표기 — 강제 매칭 금지'와
   정합이며, 축소 감쇠 수치는 0~100 점수를 편향시켜 국면 오판 위험을 남긴다.
   부족 지표는 element 평균에서 누락으로 스킵되며, 남은 지표로 평균한다(≥1 개 유효 필요).
5. **오행 지수**: 소속 지표 percentile 평균 → `round`(Python 내장 — banker). 부족 지표
   스킵, 전부 부족이면 None(국면 판정 단계에서 null 처리).
6. **클램프**: 0~100 (`scores.clamp`).
7. **window는 주기별 관측 수**: 월 120·주 520·일 2530·분기 40·연 10
   (`scores.WINDOW_COUNTS`, `scores.window_count_for` — 파이프라인이 주기별로 선택).
   GDPC1(분기)은 40, 일간 계열은 2530 — '10년'을 공통 달력 기준으로 유지.
8. **파생**: `level`(원값) · `yoy`(1년 전 대비 % — 기준점은 날짜 앵커 358~430일 창,
   결측 후보는 건너뜀) · `qoq`(직전 관측 대비 %, 간격 가드 200일) · `1y_change`(yoy 동일
   공식 — 일간 시리즈용 라벨). 기준점 확보 실패 → None → 이후 carry-forward/누락 표기.

## 5. 소스·캐시 계약 (engine/feaas/sources.py)

- fetch: 총 3시도(재시도 2회), 백오프 0.5s×2^(시도-1), timeout 기본 30s —
  실패(네트워크·HTTP 4xx/5xx·CSV 파싱) 시 `FetchError`(대상·시도 수·마지막 오류 포함).
- 캐시: `engine/data/cache/`에 **원본 응답 CSV**를 보존한다(파명 FRED `<ID>.csv`·
  Stooq `stooq-<심볼>-<주기>.csv`, tmp→replace 원자적 쓰기). 히트(refresh=False) 시
  네트워크 0호출, start/end는 메모리 필터. refresh=True만 재수집. 손상 캐시 = 미스.

## 6. 제한·한계 고지 (v2a — req §§1·5)

- 토의 임대 프록시(CUSR0000SEHA)는 공식 주거 임대지수이며 시장 임대 전파가 지연됨.
- 금의 DBAA는 신용 스프레드 프록시로서 무위험 금리 수준 혼입(순수 스프레드 아님).
- 수의 DTWEXBGS 달러 인덱스는 2006-01 시작(그 전 시점은 누락 표기된다 — 백테스트 15년
  계열에서도 동일). FRED SP500·BAML 계열의 라이선스 상한은 §3 표대로 기각 근거로 사용.
- v2b(ML·CVXPY·API 서버·PostgreSQL)는 본 정의서 스코프 밖(req-v2 머리말).
