오행 자산 진단기

FEAAS(Five Elements AI Asset Allocation System) · 1단계 MVP — 오행 자산 진단 · 배분 제안

"자산을 예측하는 것이 아니라 경제의 변화를 예측하고, 경제의 변화에 맞춰 자산의 균형을 조절한다."

1. 자산 입력

요구사항 7장 · 유형 선택(2장 투자 대상 목록 + 직접 입력), 금액, 메모

자산 추가 폼 · 항목 목록 (유형별 오행 벡터 자동 제안 + 슬라이더 조정)
— 후속 UI 티켓에서 구현

자산 데이터는 서버로 전송되지 않고 브라우저에서만 처리된다(localStorage 저장·복원은 선택 토글 — UI 티켓).

2. 포트폴리오 오행 분포

요구사항 6장·7장 · 금액 가중 평균 → 오각형 레이더 + 기준 배분(30/10/20/25/15) 오버레이 + 허용 범위 밴드

오각형 레이더 (木·火·土·金·水) — 후속 UI 티켓에서 구현
근거: src/weighted.js · src/vectors.js · src/ebi.js

분포 = 금액 가중 평균(총합 기준)으로만 만든다. UI는 계산을 재구현하지 않고 코어 모듈을 import한다.

3. 균형도 지수 (EBI)

요구사항 7장 · Energy Balance Index 0~100

EBI 0~100 게이지 (기준 배분에 가까울수록 높음) — 후속 UI 티켓에서 구현
근거: src/ebi.js · EBI_DEFINITION

4. 오행 경제지표 (수동 입력)

요구사항 4장 · 0~100 슬라이더 — 목=GDP·기업이익·PMI, 화=CPI·유가, 토=주택가격·임대수익, 금=신용스프레드·금가격, 수=유동성·달러지수

오행 경제지표 슬라이더 5개 (수동 입력 대체) — 후속 UI 티켓에서 구현

5. 경제 국면 프리셋 (A~E) → 목표 배분 제안

요구사항 3·4장 · 기준 배분에서 시프트, 허용 범위 clamp, 합 100 보정

국면 선택(A 성장 확장기 · B 인플레이션 상승기 · C 실물경제 안정기 · D 금융 불안기 · E 유동성 회복기)
+ 목표 배분 표·현재 분포와의 격차 — 후속 UI 티켓에서 구현
근거: src/regimeShift.js · REGIME_PRESETS

제안은 "검토 후 적용" 성격이다. 점수·제안이 높다고 무조건 매수가 아니라 "그 자산군에 유리한 환경인지" 판단하는 지표다.

6. 리밸런싱 힌트

요구사항 7장 · |현재 비중 − 목표 비중| ≥ 5%p인 자산군만 이동 제안 (경계 4.99%는 제안 없음)

이동 제안 목록 (±5%p 트리거) — 후속 UI 티켓에서 구현
근거: src/rebalance.js

자동 리밸런싱이 아니라 제안(힌트)이다. 자동 실행은 v2 범위(docs/v2-ideas.md)다.

7. 상생 순환 다이어그램

요구사항 5장 · 木→火→土→金→水 개념도

상생 순환 그래프 (노트 5종) — 후속 UI 티켓에서 구현
근거: src/circulate.js · CIRCULATION · CIRCULATION_NOTES

고지 문구

  • 본 도구는 투자 조언이 아니다. 실제 판단 시 수익률·위험도 등을 별도로 검증해야 한다.
  • 기준 배분(木30/火10/土20/金25/水15)은 설계용 기준이며 개인별 투자 권고가 아니다.
  • 상생 순환은 개념도다 — 실제로 모든 자산이 이 순서대로 수익을 내거나 이동하는 것은 아니다.

Gold=金: 금(Gold)·은(Silver)은 물질 기준으로 金에 속한다. v1의 火 배치는 폐기됐다(v2.0 확정 — 요구사항 0.1장). 화(火)는 금 자체가 아니라 에너지·원자재·산업금속의 가치 방어 역할이다.
