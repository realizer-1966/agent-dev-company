# GlowScript 시뮬레이터 (glowscript-web)

자연어로 물리 시뮬레이션을 설명하면 **AI가 자동으로 GlowScript/VPython 코드를 생성해 브라우저에서 실행**하는 웹앱입니다. OnDev Store에 배포됨.

## 주요 기능

- **🤖 AI 자연어 생성**: "공을 위로 던져 포물선으로 떨어지는 운동" 같은 설명을 입력하면 자동으로 시뮬레이션 매칭·실행
- **14가지 물리 시뮬레이션**: 포물선, 진자, 용수철, 궤도, 자유낙하, 충돌, 전기장, 로봇 팔, 파동, 전자기파, 유체, 간섭, 이중 진자, 태양계
- **⚙️ 파라미터 조절**: 슬라이더로 속도·질량·길이 등 조절
- **✏️ 커스텀 코드 입력**: 직접 GlowScript 코드 작성·실행
- **🔗 공유 링크**: 현재 시뮬레이션+파라미터가 포함된 URL 복사
- **📱 모바일 반응형**: 가로스크롤 버튼, 접이식 파라미터, 하단시트 모달

## 사용법

자연어 설명을 입력하고 **"생성 ▶"** 버튼을 누르거나 Enter를 누르면 됩니다.

```text
공을 위로 던져 포물선으로 떨어지는 운동   → 🎯 포물선
행성이 별 주위를 도는 궤도 운동          → 🪐 궤도
용수철이 늘어났다 줄어드는 진동          → 🌀 용수철
```

URL 파라미터로 직접 지정할 수도 있습니다:
- `?prompt=<설명>` — 자연어 매칭 실행
- `?sim=<key>` — 특정 시뮬레이션 직접 실행
- `?custom=1&code=<코드>` — 커스텀 코드 실행

## 기술 구성

- GlowScript 공식 런타임 (`glow.3.2.min.js` + `RScompiler.3.2.min.js`)
- 키워드 기반 자연어 매칭 (glowscript-agent의 `match_template` 로직을 JS로 이식)
- 컴파일러 1회 제약 때문에 파라미터/프롬프트는 URL로 인코딩해 페이지 새로고침으로 적용
- WebGL로 3D 렌더링
